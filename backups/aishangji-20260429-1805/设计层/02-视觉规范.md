## 🎯 核心视觉元素

### 1. 数据图表装饰

体现行业洞察和数据驱动的特质。

```css
/* 装饰性图表背景 */
.data-pattern {
  background-image: 
    linear-gradient(rgba(37, 99, 235, 0.03) 1px, transparent 1px),
    linear-gradient(90deg, rgba(37, 99, 235, 0.03) 1px, transparent 1px);
  background-size: 20px 20px;
}
```

### 2. 连接节点网络

体现平台作为行业枢纽的连接属性。

```css
/* 节点连接装饰 */
.network-node {
  width: 8px;
  height: 8px;
  background: #2563EB;
  border-radius: 50%;
  position: relative;
}

.network-node::after {
  content: '';
  position: absolute;
  width: 40px;
  height: 1px;
  background: linear-gradient(90deg, #2563EB, transparent);
  left: 8px;
  top: 50%;
}
```

### 3. 上升趋势线

体现商机、增长、向上的积极情绪。

```css
/* 趋势箭头 */
.trend-up {
  color: #10B981;
  display: inline-flex;
  align-items: center;
  gap: 4px;
}

.trend-up::before {
  content: '↑';
  font-weight: bold;
}
```

### 4. 简洁几何卡片

商务感的卡片设计，强调清晰的信息层级。


## 🎭 动效规范

### 过渡时间

```
快速：150ms - 微小交互（Hover）
标准：300ms - 一般交互（按钮、卡片）
慢速：500ms - 页面过渡、大型动画
```

### 缓动函数

```css
/* 标准缓动 */
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);

/* 弹性缓动 */
transition-timing-function: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```
