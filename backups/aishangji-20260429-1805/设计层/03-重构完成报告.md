## 🛠️ 技术特点

### CSS 架构

- **CSS 变量** - 统一管理颜色、间距、圆角、动效
- **响应式设计** - 移动端（<640px）、平板（640-1024px）、桌面（>1024px）
- **组件化** - 卡片、按钮、标签、筛选器等可复用组件
- **动效** - Hover 效果、过渡动画、阴影变化

### 设计系统

```css
/* 颜色 */
--primary-600: #2563EB
--success: #10B981
--text-primary: #1E293B

/* 间距 */
--space-1 ~ --space-12: 4px ~ 80px

/* 圆角 */
--radius-sm ~ --radius-full: 6px ~ 9999px

/* 阴影 */
--shadow-sm ~ --shadow-xl
--shadow-primary: 0 4px 12px rgba(37, 99, 235, 0.15)
```
