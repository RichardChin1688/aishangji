## 🎯 核心定位

### 为什么做 AI 短剧？

```
市场机会：
┌─────────────────────────────────────────────────────────────┐
│  2025-2026 年 AI 视频技术爆发（Sora、可灵、即梦等）              │
│  短剧市场规模：¥500 亿 +（2025 年）                             │
│  AI 短剧占比：<5%（蓝海市场）                                 │
│  普通人想做短剧但成本高（演员/场地/设备）                      │
│  AI 可以把成本降到 1/10 甚至更低                               │
└─────────────────────────────────────────────────────────────┘
```

### 为什么不做观众端（B2C）？

| 因素 | B2C（观众端） | B2B（产业端） | 我们的选择 |
|------|-------------|-------------|-----------|
| 竞争对手 | 红果、抖音、快手 | 暂无头部 | ✅ B2B |
| 资金需求 | 亿级起步 | 千万级可行 | ✅ B2B |
| 流量成本 | 极高 | 较低 | ✅ B2B |
| 盈利周期 | 长（3-5 年） | 短（1-2 年） | ✅ B2B |

**结论：** 红果短剧已经占了观众端，我们不做第二选择。我们做产业端，做 AI 短剧的"卖水人"！

## 📦 五大业务板块

```
┌─────────────────────────────────────────────────────────────────┐
│                      AI 短剧平台                                 │
├─────────────┬─────────────┬─────────────┬─────────────┬─────────┤
│  创作工具   │  人才市场   │  IP 交易    │  产业服务   │ 数据智库 │
│  AI 生产工具 │  人才对接   │  IP 授权    │  代制作发行  │ 数据培训 │
└─────────────┴─────────────┴─────────────┴─────────────┴─────────┘
```

| 板块 | 定位 | 服务对象 | 变现方式 |
|------|------|---------|---------|
| **创作工具** | AI 短剧生产工具 | 创作者/工作室 | SaaS 订阅 + 按量付费 |
| **人才市场** | 短剧人才对接 | 制作方/自由职业者 | 佣金 + 发布费 |
| **IP 交易** | 小说/剧本 IP 授权 | IP 方/制作方 | 佣金 + 代理费 |
| **产业服务** | 制作 + 发行服务 | 制作方/品牌方 | 服务费 + 分成 |
| **数据智库** | 行业数据 + 培训 | 全行业 | 报告 + 课程 + 咨询 |

## 🛠️ 技术栈（拟定）

### 前端
- **框架：** Next.js 14 (App Router)
- **语言：** TypeScript
- **样式：** TailwindCSS + Shadcn/ui

### 后端
- **框架：** NestJS
- **语言：** TypeScript
- **ORM：** Prisma

### 数据库
- **主库：** PostgreSQL
- **缓存：** Redis
- **搜索：** Elasticsearch
- **分析：** ClickHouse

### AI 能力
- **文生视频：** 可灵 API / Runway / Pika
- **AI 配音：** Azure TTS / ElevenLabs
- **剧本生成：** 千问 API / GPT
- **自研模型：** LoRA 微调（角色一致性）

### 基础设施
- **部署：** Vercel (前端) + Railway/阿里云 (后端)
- **GPU：** 阿里云 GPU / AutoDL
- **存储：** 阿里云 OSS
- **CDN：** Cloudflare
