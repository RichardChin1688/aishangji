## 🎬 方案 A：黑金电影感（当前方案）

### 色彩定义

```
主背景：#0F0F0F 深空黑
卡片背景：#1A1A1A 深灰
主色调：#D4AF37 戏剧金
强调色：#FFD700 聚光灯黄
文字（暗）：#FFFFFF 纯白
文字（次）：#B0B0B0 浅灰
```

### 色彩预览

```
████████ #0F0F0F 深空黑（背景）
████████ #1A1A1A 深灰（卡片）
████████ #D4AF37 戏剧金（主色）
████████ #FFD700 聚光灯黄（强调）
```

### 风格关键词

> 电影感 · 奢华 · 戏剧张力 · 高端 · 专业

### 优势

| 优势 | 说明 |
|------|------|
| ✅ **差异化明显** | 与 AI 商机（蓝色）完全区分 |
| ✅ **行业契合** | 黑金 = 影视/影院/奥斯卡 |
| ✅ **高端感** | 适合 B2B 产业服务定位 |
| ✅ **视觉冲击** | 高对比度，记忆点强 |

### 劣势

| 劣势 | 说明 |
|------|------|
| ⚠️ **暗色为主** | 部分用户可能觉得压抑 |
| ⚠️ **金色滥用** | 容易显得俗气（需控制用量） |
| ⚠️ **阅读体验** | 长文阅读不如亮色舒适 |

### 适用场景

- ✅ 高端品牌定位
- ✅ 影视/娱乐产业
- ✅ B2B 专业服务
- ✅ 追求差异化

### 代表案例

- 奥斯卡金像奖官网
- IMAX 影院官网
- 奢侈品品牌官网
- 高端汽车品牌官网
