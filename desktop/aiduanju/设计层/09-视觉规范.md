## 📏 间距系统

### 基础间距单位

```
4px  - 最小间距单位
8px  - 基础单位
16px - 常用间距
24px - 中等间距
32px - 大间距
48px - 超大间距
64px - Section 间距
80px - 大 Section 间距
100px - 超大 Section 间距
```

### 组件间距

| 组件 | 内边距 | 外边距 |
|------|--------|--------|
| 按钮 | 12px 28px | 16px（按钮组） |
| 卡片 | 24px-32px | 24px-32px（卡片间） |
| Section | 100px 0 | - |
| Container | 0 24px | - |

### 布局间距

```css
/* 网格间距 */
grid-gap: 24px;  /* 默认 */
grid-gap: 32px;  /* 大卡片 */
grid-gap: 40px;  /* 数据展示 */

/* Flex 间距 */
gap: 16px;  /* 小元素组 */
gap: 24px;  /* 中等元素组 */
gap: 40px;  /* 大元素组 */
```

## 🎭 交互效果

### 悬停效果

| 组件 | 效果 | 参数 |
|------|------|------|
| 按钮 | 上移 + 阴影增强 | translateY(-2px) |
| 卡片 | 上移 + 金色边框 | translateY(-4px) |
| 链接 | 颜色变化 | color: #D4AF37 |
| 海报 | 图片缩放 + 遮罩 | scale(1.05) + opacity |

### 加载动画

```css
/* 金色脉冲点 */
.badge-dot {
  width: 8px;
  height: 8px;
  background: #D4AF37;
  border-radius: 50%;
  animation: pulse 2s infinite;
}

@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
```

### 转场动画

```css
/* 幕布拉开效果（用于页面转场） */
@keyframes curtain-open {
  0% { transform: scaleY(1); }
  100% { transform: scaleY(0); }
}

/* 聚光灯效果（用于 Hero） */
@keyframes spotlight {
  0%, 100% { opacity: 0.15; }
  50% { opacity: 0.25; }
}
```

## 🎨 与 AI 商机的差异化

### 视觉对比表

| 元素 | AI 商机 | AI 短剧 |
|------|--------|--------|
| **主背景** | 白色/浅灰 | 深空黑 |
| **主色调** | 科技蓝 #2563EB | 戏剧金 #D4AF37 |
| **按钮** | 蓝色扁平 | 金色渐变 + 阴影 |
| **卡片** | 白底灰边 | 暗底金边 |
| **文字** | 深灰 | 白色（暗背景上） |
| **案例** | 横版卡片 | 竖版海报墙 |
| **图标** | 扁平线性 | 拟物/emoji |
| **动效** | 简洁 | 戏剧化（脉冲/聚光灯） |

### 使用场景区分

| 场景 | AI 商机 | AI 短剧 |
|------|--------|--------|
| Hero 图 | 科技渐变 | 暗色 + 金色光晕 |
| 数据展示 | 蓝色数字 | 金色数字 |
| CTA | 蓝色按钮 | 金色按钮 |
| 成功状态 | 绿色 | 绿色（保持一致） |
| 警告 | 橙色 | 幕布红 |
