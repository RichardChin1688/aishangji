# 🎬 AI 短剧 · 项目蓝图

> **一句话定位：** AI 短剧产业的"卖水人" —— 不做观众端，只做创作者的军火库
> 
> **Slogan：** 让每个人都能用 AI 拍短剧 · 让每个好故事都能变现
> 
> **愿景：** 统领 AI 短剧行业，成为行业基础设施

---

## 🎭 第一幕：为什么是现在？

### 市场时机

```
2025-2026 年  → AI 视频技术爆发（Sora、可灵、即梦）
短剧市场规模  → ¥500 亿 +（2025 年）
AI 短剧占比   → <5%（蓝海市场）
普通人门槛    → 演员/场地/设备成本高
AI 赋能       → 成本降至 1/10 甚至更低
```

### 我们的选择

| 路线 | 代表玩家 | 资金需求 | 盈利周期 | 我们的选择 |
|------|---------|---------|---------|-----------|
| **B2C 观众端** | 红果/抖音/快手 | 亿级起步 | 3-5 年 | ❌ 不碰 |
| **B2B 产业端** | 暂无头部 | 千万级可行 | 1-2 年 | ✅ 主做 |

**结论：** 红果短剧已经占了观众端，我们不做第二选择。我们做产业端，做 AI 短剧的"卖水人"！

## 🛠️ 技术栈

### 前端
- **框架：** Next.js 14 (App Router)
- **语言：** TypeScript
- **样式：** TailwindCSS + Shadcn/ui
- **动画：** Framer Motion

### 后端
- **框架：** NestJS
- **语言：** TypeScript
- **ORM：** Prisma
- **实时：** WebSocket (Socket.io)

### 数据库
- **主库：** PostgreSQL
- **缓存：** Redis
- **搜索：** Elasticsearch
- **分析：** ClickHouse

### AI 能力
- **文生视频：** 可灵 API / Runway / Pika
- **AI 配音：** Azure TTS / ElevenLabs
- **剧本生成：** 千问 API / GPT
- **自研模型：** LoRA 微调（角色一致性）

### 基础设施
- **部署：** Vercel (前端) + Railway/阿里云 (后端)
- **GPU：** 阿里云 GPU / AutoDL
- **存储：** 阿里云 OSS
- **CDN：** Cloudflare
