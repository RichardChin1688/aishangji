## 🎯 核心定位

### 三大业务支柱

```
┌─────────────────────────────────────────────────────────────────┐
│                      AI 产业研究院                               │
├─────────────┬─────────────┬─────────────┐
│  研究       │  教育       │  智库       │
│  (树品牌)   │  (建流量)   │  (做变现)   │
├─────────────┼─────────────┼─────────────┤
│  行业报告   │  在线课程   │  政府咨询   │
│  白皮书     │  认证体系   │  企业咨询   │
│  数据平台   │  实训营     │  投资顾问   │
│  专家网络   │  就业服务   │  专家顾问   │
└─────────────┴─────────────┴─────────────┘
```

| 支柱 | 定位 | 服务对象 | 变现方式 |
|------|------|---------|---------|
| **研究** | 树品牌 | 政府/企业/投资人 | 报告销售 + 数据订阅 |
| **教育** | 建流量 | 学生/从业者/企业 | 课程 + 认证 + 实训 |
| **智库** | 做变现 | 政府/企业/投资机构 | 咨询项目 + 顾问费 |

### 为什么做 AI 产业研究院？

| 市场痛点 | 我们的解决方案 |
|---------|--------------|
| AI 行业混乱，缺权威声音 | 深度研究 + 客观分析，建立信任 |
| 企业想转型但不懂 AI | 战略咨询 + 培训，一站式服务 |
| 政府想发展 AI 但缺规划 | 产业规划 + 招商支持 |
| 从业者想学习但缺系统课 | 体系化课程 + 认证 |
| 投资人想看深度分析 | 行业数据 + 项目尽调 |

## 🛠️ 技术栈（拟定）

### 前端
- **框架：** Next.js 14 (App Router)
- **语言：** TypeScript
- **样式：** TailwindCSS + Shadcn/ui
- **移动端：** 响应式 + 小程序

### 后端
- **框架：** NestJS
- **语言：** TypeScript
- **ORM：** Prisma

### 数据库
- **主库：** PostgreSQL
- **缓存：** Redis
- **搜索：** Elasticsearch
- **分析：** ClickHouse

### 基础设施
- **部署：** Vercel (前端) + 阿里云 (后端)
- **存储：** 阿里云 OSS
- **视频：** 阿里云视频点播
- **CDN：** Cloudflare

## 🔄 与"AI 商机"、"AI 短剧"的关系

### 独立运营
- 独立域名、独立品牌
- 独立团队（可共享部分资源）
- 独立财务核算

### 协同效应
- **内容互通** - 研究报告可在 AI 商机展示
- **用户导流** - 教育学员可导流至 AI 商机/AI 短剧
- **专家共享** - 专家网络可服务三个项目
- **资本故事** - 三个项目打包，生态更完整

### 三个项目定位对比
| 项目 | 定位 | 复杂度 | 建议启动顺序 |
|------|------|--------|-------------|
| AI 短剧 | 工具 + 服务 | ⭐⭐ | 1️⃣ |
| AI 商机 | 信息 + 工具 + 交易 | ⭐⭐⭐ | 2️⃣ |
| AI 产业研究院 | 研究 + 教育 + 智库 | ⭐⭐⭐⭐⭐ | 3️⃣ |
