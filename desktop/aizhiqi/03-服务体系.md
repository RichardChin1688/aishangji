## 📦 Layer 1：基础设施与应用层

**定位：** 让企业零门槛、低成本、安全用上 AI

### 1.1 AI 本地私有部署

| 项目 | 说明 |
|------|------|
| **服务内容** | 将 AI 模型/应用部署到企业内网或私有云 |
| **核心价值** | 数据不出内网、安全合规、自主可控 |
| **目标客户** | 国企/央企、金融、医疗、政府、上市公司 |
| **交付周期** | 2-8 周 |
| **价格区间** | ¥50-500 万（一次性）+ 15-20%/年维保 |
| **技术栈** | Docker/K8s、OpenStack/VMware、本地 GPU 集群 |

**服务明细：**
- 环境评估与方案设计
- 模型部署（千问/GPT/Claude 等）
- 私有化知识库搭建
- API 网关与权限管理
- 数据加密与安全加固
- 运维培训与文档交付
