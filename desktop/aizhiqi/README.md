## 🎯 核心定位

### 三大业务支柱

```
┌─────────────────────────────────────────────────────────────────┐
│                        AI 智企                                   │
├─────────────┬─────────────┬─────────────┐
│  私有化部署  │  行业 SaaS  │  智能体定制  │
│  (大客户)   │  (中小客户)  │  (高端客户)  │
├─────────────┼─────────────┼─────────────┤
│  本地部署    │  电商 SaaS  │  客服 Agent  │
│  私有云      │  客服 SaaS  │  销售 Agent  │
│  混合云      │  营销 SaaS  │  运营 Agent  │
│              │  办公 SaaS  │  管理 Agent  │
└─────────────┴─────────────┴─────────────┘
```

| 支柱 | 定位 | 目标客户 | 客单价 | 交付周期 |
|------|------|---------|--------|---------|
| **私有化部署** | 大客户 | 大型国企/央企/上市公司 | ¥50-500 万 | 3-6 个月 |
| **行业 SaaS** | 中小客户 | 中小企业/创业公司 | ¥1-50 万/年 | 1-4 周 |
| **智能体定制** | 高端客户 | 科技企业/金融机构 | ¥20-200 万 | 1-3 个月 |

### 为什么做 AI 智企？

| 市场痛点 | 我们的解决方案 |
|---------|--------------|
| 企业想用 AI 但不会用 | 提供一站式服务（咨询 + 部署 + 培训） |
| 数据敏感不能上公有云 | 私有化部署，数据不出内网 |
| 通用 AI 不匹配行业场景 | 行业 SaaS，垂直场景优化 |
| 缺 AI 人才 | 智能体定制，替代/辅助人力 |
| 供应商太多难选择 | 总包商模式，一站式采购 |

## 🛠️ 技术栈（拟定）

### 前端
- **框架：** React + TypeScript
- **UI：** Ant Design
- **移动端：** 小程序 + H5

### 后端
- **框架：** Spring Boot + Java 或 NestJS + TypeScript
- **API：** REST + gRPC

### AI 能力
- **大模型：** 千问/GPT/Claude
- **私有模型：** LoRA 微调
- **向量数据库：** Milvus/Pinecone
- **知识库：** RAG 架构

### 数据库
- **主库：** PostgreSQL
- **缓存：** Redis
- **搜索：** Elasticsearch
- **消息队列：** Kafka

### 部署
- **容器化：** Docker + K8s
- **私有云：** OpenStack/VMware
- **公有云：** 阿里云/腾讯云
